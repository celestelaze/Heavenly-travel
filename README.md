# ✈️ HEAVENLY TRAVEL — Agence de Voyage Premium

Site web officiel de **Heavenly Travel**, agence de voyage basée au Maroc, spécialisée dans les vols, hébergements et voyages sur-mesure.

---

## 🌐 Site en ligne

> Déployé sur Vercel — lien disponible après déploiement

---

## 🛠️ Technologies utilisées

| Technologie | Rôle |
|---|---|
| React 18 | Framework UI |
| TypeScript | Typage statique |
| Vite 5 | Bundler & dev server |
| Tailwind CSS | Styles utilitaires |
| shadcn/ui | Composants UI |
| React Router v6 | Navigation SPA |

---

## 📄 Pages

- **Accueil** `/` — Hero, destinations, services, témoignages
- **Réserver un vol** `/reserver-vol` — Formulaire de réservation de vols
- **Réserver hébergement** `/reserver-hebergement` — Formulaire hôtels & séjours
- **Planifier un voyage** `/planification-voyage` — Voyage sur-mesure

---

## 🚀 Lancer le projet en local

```bash
# Installer les dépendances
npm install

# Démarrer le serveur de développement
npm run dev

# Build de production
npm run build
```
